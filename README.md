# 🌾 KisanAI – The Ultimate AI/ML-Powered Smart Farming Platform

KisanAI is an AI/ML-powered smart farming platform that leverages cutting-edge technologies to optimize farming operations, increase productivity, and ensure sustainable agricultural practices. The platform provides real-time insights, automation, and predictive analytics to help farmers make data-driven decisions.

## 🚀 Key Features
- **Farm Mapping** – Digitally map your farm for better monitoring and planning.
- **AI-Powered Crop Recommendations** – Get optimal crop suggestions based on soil type, weather, and market trends.
- **Dynamic Weather Alerts & News** – Stay informed with AI-powered real-time weather updates.
- **10-Day Weather Forecast** – Plan ahead with extended weather predictions.
- **Sapodilla Disease Detection** – AI-driven disease detection for healthier crops.
- **Weather Data Analytics** – Gain insights from detailed weather analytics.
- **AI-Powered LLMs (Gemini, DeepSeek, Claude, etc.)** – Leverage AI-powered models for smarter farming decisions.
- **Full Farm Management CRM** – AI-integrated management of logistics, inventory, reports, and expenditure.
- **Cost, Logistics, Inventory, & Reports Management** – Streamline farm operations with AI-powered analysis.
- **24/7 Weather Station Alerts** – Get real-time alerts from weather stations for proactive decision-making.

## 📦 Installation & Setup
### Prerequisites
- Node.js installed
- Supabase account setup
- AWS credentials configured for deployment


### Deployment on Netlify
1. Connect your GitHub repository to Netlify.
2. Set up environment variables for Supabase and AWS.
3. Deploy your frontend directly from Netlify’s dashboard.
